OpenHamShack QO-100 NB / OpenHamShack Radio for Windows - what else is in this folder
=====================================================================================

OpenHamShack QO-100 NB and OpenHamShack Radio are free software under the GNU General Public
License, version 3 or later (LICENSE, beside this file). Each one's
Windows build also carries the following, each under its own licence
(the texts are in licences/, beside this file, under the names given
below). Nothing here has been modified.

Source code: the program's own complete source - OpenHamShack QO-100 NB or
OpenHamShack Radio itself, including ohsdigi (below), its FT8/FT4 encoder - is published for
every release, as openhamshack-nb-<version>-src.tar.gz or
openhamshack-radio-<version>-src.tar.gz, on the OpenHamShack projects' source site, in
this program's section:
    https://openhamshack.com/source/#openhamshack-nb
    https://openhamshack.com/source/#openhamshack-radio
The same section has the exact source release of every GPL and LGPL
component below - the one each binary was built from. It says which
tarball is the source of which files here, and its SHA256SUMS checks them. The upstream addresses below are where each was
taken from; the copies on the source site stay up for as long as an
installer that carries them is offered.

    https://github.com/pyca/bcrypt  https://github.com/pyca/pynacl

codec2 - libcodec2.dll (LGPL-2.1; licences/codec2-COPYING)
LPCNet - liblpcnetfreedv.dll (BSD-3-Clause; licences/lpcnet-COPYING)
    Taken unmodified from FreeDV-GUI 1.9.9.2's Windows release
    (FreeDV-1.9.9.2-windows-x86_64.exe, bin\) - the 2.x releases no longer
    ship codec2 as a separate DLL. Sources:
    https://github.com/drowe67/codec2  https://github.com/drowe67/LPCNet
    https://github.com/drowe67/freedv-gui/releases/tag/v1.9.9.2
    FreeDV-GUI 1.9.9.2 builds codec2 at tag 1.2.0 (codec2-1.2.0.tar.gz
    on the source site).
    You may replace either DLL with your own build of the same library.

libiio 0.26 - iio.py and libiio/libiio.dll
    (LGPL-2.1-or-later; licences/libiio-COPYING.txt)
    Analog Devices' pure-Python bindings and the library they load, both
    unmodified from ADI's libiio 0.26 Windows release (Windows.zip,
    Windows-VS-2022-x64\). Only the library is here, not ADI's iio_*
    command-line tools (which are GPL-2.0 and not needed). Source:
    https://github.com/analogdevicesinc/libiio/releases/tag/v0.26
    (tag v0.26). libiio.dll is loaded at run time from its own folder and
    may be replaced with your own build of libiio 0.26 there.

    The three libraries libiio.dll is linked against, from the same ADI
    release, unmodified, in the same folder:

    libxml2 2.9.12 - libxml2.dll (MIT; licences/libxml2-Copyright)
        https://gitlab.gnome.org/GNOME/libxml2 (tag v2.9.12)
    libusb 1.0.24 - libusb-1.0.dll (LGPL-2.1-or-later; licences/libusb-COPYING)
        https://github.com/libusb/libusb/releases/tag/v1.0.24
    libserialport 0.1.1 - libserialport-0.dll (LGPL-3.0-or-later;
        licences/libserialport-COPYING, which builds on the GPL-3.0 in
        LICENSE beside this file)
        https://sigrok.org/wiki/Libserialport (tag libserialport-0.1.1)

    Each may be replaced with your own build of the same library. The
    versions are the ones the DLLs themselves report; each licence was
    fetched from that exact tag.

PlutoSDR-M2k USB drivers v0.9 - run by the installer, not installed here
    (Analog Devices' licence; licences/plutosdr-m2k-drivers-LICENSE)
    The setup program carries ADI's PlutoSDR-M2k-USB-Drivers.exe v0.9
    unmodified and runs it when "Install the PlutoSDR USB drivers" is
    ticked; it installs into Program Files\Analog Devices\PlutoSDR-M2K
    and is removed from Settings > Apps under its own name.
    https://github.com/analogdevicesinc/plutosdr-m2k-drivers-win/releases/tag/v0.9
    ADI's licence is BSD-style: binary redistribution is allowed with the
    copyright notice and licence reproduced (licences/), without using
    ADI's name to endorse this program, and with the condition that the
    software is used with an Analog Devices part - which these drivers
    are: they match only the ADALM-Pluto/M2k USB IDs. ADI's package
    itself contains Microsoft's DPInst and WinUSB/WDF co-installers
    (Windows Driver Kit redistributables) and ADI's build of dfu-util
    0.8 (GPL-2.0-or-later; its COPYING is inside ADI's package), which
    has libusb 1.0.19 (LGPL-2.1-or-later) linked in. Source on the source site:
    dfu-util-0.8.tar.gz and libusb-1.0.19.tar.bz2, from
    https://dfu-util.sourceforge.net/releases/dfu-util-0.8.tar.gz and
    https://sourceforge.net/projects/libusb/files/libusb-1.0/libusb-1.0.19/

cty.dat - ohscore/data/cty.dat (MIT; licences/cty.dat-copyright.txt,
also beside it)
    Jim Reisert AD1C's country file, for the FT8 Country column: Big CTY
    as published on https://www.country-files.com/, unmodified; the
    edition and the sha256 of its download are in ohscore/data/cty-source.txt.
    The MIT licence permits copying and redistribution with the notice
    included. https://www.country-files.com/copyright/
    A newer cty.dat placed in %APPDATA%\openhamshack-nb\data (or openhamshack-radio)
    is used instead. (Up to 0.1.9 the installer carried WSJT-X 2.7.0's
    copy, in wsjtx/share/wsjtx.)

ohsdigi - ohscore/ohsdigi.pyd (GPL-3.0-or-later; licences/ohsdigi-LICENSE-THIRD-PARTY.txt)
    The FT8, FT4, Q65 and JS8 decoders and encoders: OpenHamShack's own Rust code (rust/ohsdigi in its
    source), part of the program and under its GPL-3.0-or-later. Much of
    it is ported from WSJT-X 2.7.0 (GPL-3.0-or-later), copyright (C)
    2001-2023 Joe Taylor K1JT, Steve Franke K9AN, Bill Somerville G4WJS,
    Nico Palermo IV3NWV and the WSJT Development Group. Its HSmodem
    module (the QO-100 multimedia beacon's modem) is ported from HSmodem,
    (C) Kurt Moraw DJ0ABR, GPL version 2 or later
    (https://github.com/amsat-dl/QO-100-Modem), and from liquid-dsp,
    Copyright (c) 2007-2020 Joseph Gaeddert, MIT licence
    (https://github.com/jgaeddert/liquid-dsp). Compiled into it
    are the Rust crates PyO3 0.29.3 and pyo3-ffi (PyO3 Project and
    Contributors), libc 0.2.190 (The Rust Project Developers), once_cell
    1.21.4 (Aleksey Kladov) and the Rust 1.98.1 standard library (The Rust
    Project Contributors), each under the MIT licence (or Apache-2.0, at
    the user's choice); their notices and the MIT text are in
    licences/ohsdigi-LICENSE-THIRD-PARTY.txt. The crates are used
    unmodified, at the versions rust/ohsdigi/Cargo.lock pins. Being built
    with the MinGW-w64 toolchain, it also has GCC's libgcc linked in
    (GPL-3.0 with the GCC Runtime Library Exception;
    licences/gcc-COPYING.RUNTIME) and the mingw-w64 runtime's start-up
    code (public domain and MIT-style; licences/winpthreads-COPYING).

WDSP noise reduction (GPL-2.0-or-later)
    The receive noise reduction (NR2) is a port of emnr.c from WDSP 2.10 by
    Warren Pratt, NR0V, with his GG/GGS gain tables (ohscore/dsp/nr.py,
    nr_tables.npz); part of the program and under its GPL-3.0-or-later.
    https://github.com/TAPR/OpenHPSDR-wdsp
