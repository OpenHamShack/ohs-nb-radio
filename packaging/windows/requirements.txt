# What tools/build-windows.ps1 installs into its build virtualenv: the
# program's own requirements (DESIGN.md: numpy, PyQt6, pyaudio) plus
# PyInstaller. Pinned, so two builds of one version carry the same bytes;
# move them deliberately, and rebuild and re-run the suite under Windows
# when you do. PyAudio's Windows wheels carry PortAudio themselves.
# pyserial is NB's CI-V link to an IC-9700 used as the transmitter (the
# radio's USB port is a COM port); pure Python.
# cryptography (with cffi) checks the update feed's Ed25519 signature
# (ohscore/update.py) in both apps, from 07/10/2026.
# paramiko is HAM's SSH client for the Pluto's AD9364 setting
# (ohsradio/plutofix.py); pinned to the version Debian 13 ships and the suite
# runs against. Its dependencies come as binary wheels for Windows; pinned
# at what pip resolved on the Windows build machine (06/10/2026), because THIRD-PARTY.txt
# names each one's version and licence file and must stay true.
# (pycparser is cffi's build-time parser: installed, never bundled.)
# hidapi and Pillow are the AKP03E controller pad's (shack_pad): hidapi
# is how Windows reaches it (the wheel carries the hidapi C library
# itself), Pillow draws its key pictures. Before 12/10/2026 neither was
# here, so the pad could not work on Windows at all and nothing said so.
