# The Corresponding Source for the third-party GPL and LGPL code inside the
# macOS apps (tools/build-macos.sh), in packaging/windows/sources.txt's
# format - read that file for the fields and for why we host the source
# ourselves rather than point upstream:
#   file | sha256 | licence | installers that carry it | what it is the source of | url [fallback url ...]
#
# tools/release.sh [nb|ham] --macos publishes this list - as it was at the
# commit the .dmg was built from - on the shared source site as the
# manifest openhamshack-nb-macos or openhamshack-radio-macos (--carried-by NB or HAM,
# as with Windows), together with that commit's own source, and refuses to
# put the .dmg on the site unless every tarball is there and verified. A
# section of its own rather than lines in the Windows installer's: the
# sets differ (libad9361 here, libusb and dfu-util there), and each must stay exactly
# as long as its own download is offered. The Mac-only tarballs were
# fetched from the URLs below on 07/10/2026 and matched these hashes.
#
# WSJT-X 2.7.0 and the libraries its tools loaded (Qt 5.15.2, FFTW 3.3.8,
# GCC 8.2.0's libquadmath) were listed here until 17/10/2026, when the Mac
# apps stopped carrying them (tools/build-macos.sh); the manifests already
# published for the .dmg files that did carry them keep their lines.
#
# How each was identified (07/10/2026):
#   - libiio, libad9361, codec2: the release tarballs build-macos.sh builds
#     from, by the same hashes it pins.
#   - PortAudio (MIT) and Python's own libraries (PSF, Apache-2.0, MIT,
#     BSD, public domain) need no source.
